No single reference — this one is a blend, so its sources are toolkits 02, 05 and 04.

How to read these. All six live in the same contemporary family, so the choice is about which system rather than which century. Nocturne sorts by colour before you read a number. Mosaic gives every question its own saturated field. Citron removes axis-reading entirely by putting the value inside the mark. Daylight is the calm one — a single hue and a hatch pattern answer everything. Pigment encodes the rules-vs-model distinction in colour itself. Alloy takes Mosaic's structure, Pigment's light and Daylight's voice, and holds a verified contrast floor through every hover state.

What's in each. An overview collage, then colour, type, shape, depth and gradients, controls, faces, four charts, the drop in situ with empty and loading states, and a copy-paste CSS custom-property block. Same components and the same synthetic cohort throughout, so they compare on craft rather than mood.
