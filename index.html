Scout 0.1 · alpha

A talent origination engine for Paradium. Scout is the app you look at; the engine is what does the reading.

Open Scout → The current build. Runs off a frozen seed — no server, no key. Every build, side by side The current one and the ten it came from. Needs the server below.

Run it against the live engine

cd App/engine && node bin/serve-live.js 8140

Then open http://localhost:8140/scout/. A brief written in Scout starts a real run and spends real money. Without the model key it falls back to a seeded scan and says so.

Serve the whole folder

node Archive/prototypes/serve.js

Then open http://localhost:4321 — this page, with every build reachable. Pass a port number if 4321 is taken.
